## 🔬 Research

### Hardware Trojan Detection Using Lightweight Machine Learning

My research focuses on detecting **Hardware Trojans in commercial off-the-shelf hardware** using efficient Machine Learning techniques.

**Technologies & Methods:**

* Random Forest
* Support Vector Machine (SVM)
* XGBoost
* Stacking Ensemble
* SHAP Explainability
* SMOTE / ADASYN
* Signal-Level Features
* SCOAP Metrics

The goal is to develop an efficient and explainable approach to hardware security that can achieve strong detection performance without requiring expensive computational resources.
