# 🔬 Research

## Hardware Trojan Detection Using Lightweight Machine Learning

My research focuses on detecting **Hardware Trojans in Commercial Off-The-Shelf (COTS) hardware** using efficient Machine Learning techniques.

### Technologies & Methods

* Random Forest
* Support Vector Machine (SVM)
* XGBoost
* Stacking Ensemble
* SHAP Explainability
* SMOTE / ADASYN
* Signal-Level Features
* SCOAP Metrics

The goal is to build an efficient and explainable hardware security solution that achieves strong detection performance without requiring expensive computational resources.
